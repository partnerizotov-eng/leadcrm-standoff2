# Lead CRM — холодный аутрич в ВК

Инструмент для команды менеджеров (ручной аутрич, без автоматизации отправки —
пишете сами из своих VK-аккаунтов, система организует процесс и считает результат).

## Запуск
```
pip install -r requirements.txt
cp .env.example .env   # впишите ADMIN_LOGIN/ADMIN_PASSWORD, SECRET_KEY
python run.py
```
Первый вход — под ADMIN_LOGIN/ADMIN_PASSWORD из .env. Дальше админ создаёт
менеджеров в разделе «Менеджеры».

## Что внутри
- **Дедупликация**: один и тот же ВК-профиль не может попасть в базу дважды —
  если лид уже у кого-то, менеджеру сразу видно, у кого и в каком статусе.
- **Round-robin с балансировкой**: массовый импорт (админ вставляет список
  найденных профилей) распределяется на наименее загруженных активных
  менеджеров, а не по жёсткой очереди.
- **Скрипты с конверсией**: несколько вариантов первого сообщения,
  автоматический % ответивших по каждому — видно, какой текст реально работает.
- **Воронка**: новый → написали → ответил → вступил в канал → участвовал →
  возвращается (после 2+ участий).
- **Учёт розыгрышей**: 3 слота в день (12:00/18:00/00:00), идемпотентная
  отметка участия — повторный клик не завышает счётчик.
- **Рейтинг менеджеров**: конверсия и число «вернувшихся» лидов по каждому,
  видно кто реально работает, а не просто пишет много.

## Тесты
```
python -m unittest discover -s tests -v
```
74 теста: нормализация VK-ссылок, дедупликация, round-robin с балансировкой,
воронка, идемпотентность участия, RBAC (менеджер видит только своих лидов),
безопасность (CSRF, rate limiting, блокировка неактивных аккаунтов), а также
весь платёжный цикл — начисление менеджеру, вывод его баланса, комиссия,
ручные корректировки.

## Система баланса и выплат

- **Заявка на участие**: менеджер прикрепляет скриншот с игровым ID лида в
  комментариях → уходит на проверку. Одобряет только администратор.
- **Начисление**: одобрение = +10G лиду (виден его прогресс участия;
  второе одобрение — статус «Возвращается») **и +10G самому менеджеру**,
  приславшему заявку — это его собственный, выводимый баланс. Отклонение
  ничего не начисляет, но комментарий админа виден менеджеру и в
  уведомлении — чтобы было что ответить лиду.
- **Прямой чат**: кнопка «💬 Написать» у каждого лида — открывает диалог в ВК.
- **Вывод от 30G — только у менеджера, за свой собственный баланс**: как
  только на балансе менеджера набирается от 30G, на странице «Выводы»
  становится доступна кнопка «Запросить вывод». Баланс списывается сразу
  при заявке (без гонок — проверено под конкурентным доступом). Система
  сама считает цену листинга с учётом комиссии (настраивается
  администратором) и случайных копеек. Менеджер присылает скриншот продажи
  → администратор подтверждает (можно со своим скриншотом) → готово.
  Отклонение на любом этапе до завершения возвращает баланс менеджеру
  полностью. Баланс лида остаётся только информационным показателем
  прогресса — вывести его напрямую нельзя.
- **Ручная корректировка баланса** — только у администратора (отдельно для
  баланса лида и для баланса менеджера), всегда с причиной, всегда в
  журнале операций (`balance_ledger` / `manager_ledger`), затронутая
  сторона получает уведомление.
- **Уведомления** — колокольчик в шапке, растёт на каждое событие
  (новая заявка, решение, инструкция по выводу, изменение баланса).

## Управление менеджерами
- **Импорт из Excel** (.xlsx, столбцы «Имя»/«Логин»/«Пароль» — логин и пароль
  генерируются автоматически, если пусты). Раздел «Менеджеры».
- **Экспорт логинов в TXT** — список текущих логинов (пароли захешированы и
  не восстанавливаются; полные пары логин+пароль доступны один раз, сразу
  после создания/импорта, файлом на скачивание).
- **Редактирование** — админ меняет имя, логин и пароль любому менеджеру.
- **Аналитика по каждому менеджеру**: заработок, обработано заявок, новых
  лидов за сутки/неделю/всё время, время работы (считается по сессиям
  вход/выход), ожидающий баланс их лидов. **TOP-3** по заработку — на
  дашборде и в разделе «Менеджеры».

## Журнал действий
Раздел «Журнал действий» (только админ) — единая лента: создание/изменение
менеджеров, решения по заявкам и выводам, ручные корректировки баланса,
изменение комиссии, входы/выходы. Решения по заявкам и выводам также видны
точечно в самих карточках заявки/вывода.

## Честная граница
Ссылка на листинг скина за конкретную сумму — это подсказка менеджеру,
что ввести на площадке Standoff 2 вручную. Сама покупка/продажа скина
происходит вне системы. Стоит свериться с правилами площадки Standoff 2
насчёт листинга по цене выше номинала ради компенсации комиссии — это
не проверено на соответствие их условиям использования.
